# 🛡️ Gujarat Police Prep - Master Admin App

આ એપ્લિકેશન દ્વારા તમે મુખ્ય વિદ્યાર્થી એપનું તમામ સંચાલન (Management) કરી શકો છો.

## 🌟 મુખ્ય સુવિધાઓ:
1. **Excel / CSV થી 200 પ્રશ્નોનું બલ્ક અપલોડ**:
   - કોન્સ્ટેબલ (LRD) અથવા PSI / ASI પસંદ કરો.
   - ટેસ્ટ નંબર પસંદ કરો અને CSV ફાઈલ પેસ્ટ કરીને એક જ ક્લિકમાં અપલોડ કરો.
2. **મોક ટેસ્ટ ફ્રી / લૉક મેનેજર**:
   - કોઈપણ મોક ટેસ્ટને એક ક્લિકમાં ફ્રી અથવા પ્રીમિયમ લૉક કરી શકો છો.
3. **Supabase ડેટાબેઝ ઇન્ટીગ્રેશન**:
   - Supabase Project URL અને API Key સેવ કરીને તમામ વિદ્યાર્થીઓના ફોનમાં રિયલ-ટાઇમ સિંક કરી શકો છો.
