# 🛡️ PSI Mock Test - Master Admin App (Firebase Edition)

આ એપ્લિકેશન દ્વારા તમે મુખ્ય વિદ્યાર્થી એપનું તમામ સંચાલન (Management) Firebase Firestore અને Firebase Authentication સાથે સુરક્ષિત રીતે કરી શકો છો.

## 🌟 મુખ્ય સુવિધાઓ:
1. **Firebase Authentication એડમિન લૉગિન**:
   - Firebase Console માં બનાવેલ એડમિન Email અને Password વડે સુરક્ષિત લૉગિન.
2. **મોક ટેસ્ટ અને પ્રશ્નોનું બલ્ક ઇમ્પોર્ટ**:
   - કોન્સ્ટેબલ (LRD) અથવા PSI / ASI મોક ટેસ્ટ પસંદ કરી JSON/CSV દ્વારા 100/200 પ્રશ્નો એકસાથે ઇમ્પોર્ટ કરો.
   - પ્રશ્નો સિલેબસ ટોપિક મુજબ ડાયનેમિક સેટ થાય છે જેથી વિદ્યાર્થીઓ મોક ટેસ્ટ અને ટોપિક વાઈઝ બંને જગ્યાએ પ્રેક્ટિસ કરી શકે.
3. **મોક ટેસ્ટ ફ્રી / લૉક મેનેજર**:
   - કોઈપણ મોક ટેસ્ટને એક ક્લિકમાં ફ્રી અથવા લૉક કરી શકો છો.
4. **વિદ્યાર્થીઓ અને પ્રોફાઇલ સિંક**:
   - Firebase Firestore માં સાઇન-અપ થતાં તમામ નવા વિદ્યાર્થીઓ અહીં લાઈવ દેખાશે.
5. **વિડ્રોઅલ અને કોઈન્સ મેનેજમેન્ટ**:
   - વિદ્યાર્થીઓની પેમેન્ટ રિક્વેસ્ટ મંજૂર કે અસ્વીકાર કરી શકો છો.
